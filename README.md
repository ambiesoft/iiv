# iiv

Clipboard image monitor + external image viewer.

## Projects

- `iiv_mon`: native Win32 clipboard monitor / tray application.
- `iiv_view`: WPF image viewer (.NET 8).

This is the initial skeleton. The next implementation steps are:
1. configuration file under the application directory
2. viewer registration and launch mode (clipboard/file)
3. temporary image handling
4. richer tray notifications
5. viewer command-line file support
